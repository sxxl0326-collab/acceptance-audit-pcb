Freeze code and inputs before computing outcomes. Retain the saved PCB Qwen Source-parameter and Numeric feedback cohorts, both execution controllers and the old and new injected cohorts. Reuse verified single-gate results. Run Empty+Warning+Direction and Empty+Warning+Direction+Value through the same SQLite execution function. Count valid effects, invalid effects, deferrals, valid advisory effects withheld, prevented invalid effects, workload divided by prevented effects, and ideal recovery. An undefined ratio has zero prevented effects. Ideal recovery replaces the contract with the source reference and replans on the same finite catalogue and script. It is an upper-bound scenario for that modeled correction procedure.

The value check uses the source quantity only when the PCB clause identifies one metric, one unambiguous direction and one number in the supported native unit. Compare the normalized unary threshold only when directions agree. This avoids treating a direction error as an independent value error. Abstain on unknown units, conflicting cues, mixed rows or ambiguous numbers. Injected threshold errors are authored probes. The gate does not depend on reference rows or eventual effect outcomes.

Record duplicate returns separately. For saved cases, also replay the other capacity's generated contract, which is a different contract. Deduplicate alternate outcomes by request, model and script within each controller and cohort. The analysis is conditioned on selected valid effects, so it does not estimate general exposure risk.
